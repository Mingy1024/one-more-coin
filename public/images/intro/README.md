# Intro artwork

`dream-machine.webp` was generated with OpenAI's built-in image generation tool and converted to a 512px transparent WebP for the game intro screen.

Prompt:

> Create one original transparent-background PNG illustration for the intro screen of a whimsical online claw machine game. Center a dreamy miniature claw machine portal floating among soft pearlescent clouds and tiny crescent moons, with one round cuddly plush creature visible inside the glass and a small open golden claw hovering above it. Manga storybook illustration with confident dark navy ink outlines, ornate polished gold trim, teal/turquoise glass, soft lavender and blush coral highlights, luminous star sparkles. Magical, playful, slightly absurd, premium arcade poster quality. Portrait-ish compact composition that reads clearly at 150px wide on mobile and 240px wide on desktop, fully contained with generous transparent margins. NO text, NO letters, NO logos, NO numbered coins, NO watermark, no background rectangle. Actual transparent alpha background.
