# UI artwork

`coin-token.webp` was generated with OpenAI's built-in image generation tool, then resized to a 256px transparent WebP. The token center is intentionally blank; the start button label states the amount in both languages.

Prompt:

> Create a single compact transparent-background PNG game UI icon: one golden arcade token viewed nearly face on with a slight 3/4 tilt, ornate raised concentric rim, a BLANK smooth center medallion large enough to place a number in HTML later, tiny star embossing only along outer rim, teal enamel edge, restrained coral and turquoise sparkle accents. Match a polished whimsical manga claw machine game: bold dark navy ink outlines, warm gold highlights, crisp small-size readability at 44 pixels. One isolated token, no hands, no water splash, no background, no text, no digits, no logo, no watermark. Preserve actual alpha transparency and generous transparent margin.
